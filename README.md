# Poznávačka rostlin – ČZA Mělník

Kartičky s fotkami rostlin pro procvičování na poznávačky: podle fotky doplň latinský a český název.

- Letničky č. 1 (32 druhů), č. 2 (37 druhů) a č. 3 – náhradní (7 druhů)
- výběr sad, režim Mix, ukládání pokroku jen v prohlížeči

Web: https://bocrew.com

Struktura: `index.html` (aplikace), `data/sets.js` (oblasti, sady a názvy), `img/<sada>/NN.jpg` (fotky).
Fotografie a názvy rostlin pocházejí ze studijních materiálů ČZA Mělník.
