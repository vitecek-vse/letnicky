# Poznávačka rostlin – letničky

Neziskový projekt určený výhradně k tréninkovým účelům: kartičky s fotkami rostlin pro procvičování poznávání letniček podle latinských a českých názvů.

Web: https://bocrew.com

Struktura: `index.html` (aplikace), `data/sets.js` (sady a názvy), `img/<sada>/NN.webp` (fotky).
